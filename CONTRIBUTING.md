# Contributing

## The bar

An entry gets in if you have installed it, run it, and it did the thing it claims. Stars are not evidence.

## Format

One line, exactly this shape, no trailing period:

```
- [name](url) - what it does in one line
```

Keep entries alphabetical inside a section unless the section says otherwise.

## Rules

1. One entry per pull request. It keeps the review honest.
2. Never add a link you have not opened. A dead link is worse than an empty section.
3. No self promotion disguised as a category. Put your own work in the section it belongs to and say it is yours in the PR body.
4. If a category is empty, leave the "PRs welcome" placeholder rather than inventing a URL to fill it.
5. Duplicates and thin forks of an existing entry get closed.

## PR body

Say what you installed, what command you ran, and what happened. Two lines is enough.
